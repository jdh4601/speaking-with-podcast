# Podcast Study for iPhone

Mac에서 에피소드·표현·원문 음성을 준비하고, 아이폰에서 오프라인으로 학습하는 개인용 앱입니다. iOS 17 이상을 대상으로 합니다. 첫 버전은 서버·계정·클라우드 동기화 없이 `.podstudy` 파일을 가져옵니다.

## Mac → iPhone

1. Mac의 English Routine 앱을 다시 실행합니다. 팟캐스트 학습에서 학습 기록의 에피소드를 선택합니다.
2. **원문 음성 포함 → 아이폰 학습 꾸러미 만들기**를 누릅니다. 처음에는 원본 다운로드와 문장 정렬에 시간이 걸릴 수 있습니다. 이미 준비한 문장은 캐시를 사용합니다.
3. 완료 후 **꾸러미 저장**을 누릅니다. iCloud Drive나 AirDrop으로 아이폰에 옮깁니다. 파일에 계정 토큰, Codex 설정, 전체 전사, 전체 녹음은 포함되지 않습니다.
4. 아이폰 앱에서 **학습 꾸러미 가져오기**로 파일을 선택하거나 파일 앱의 공유 메뉴에서 Podcast Study로 엽니다. 기기에 복사된 뒤에는 원본 파일이나 Mac 연결이 필요 없습니다.
5. 원음이 빠진 카드는 이유가 표시됩니다. Mac에서 음성 준비 후 같은 에피소드를 다시 내보내고 가져오면 됩니다.

파일을 다시 가져오면 해당 에피소드의 내용·음성을 교체합니다. 동일한 표현과 인용의 고정 ID를 사용해 저장 여부와 복습 기록을 보존합니다. 새 파일에 음성이 없으면 이전 음성을 유지하지 않습니다.

## iPhone 설치

현재 Xcode 26.6에서 iOS Simulator 빌드가 통과했고, iOS 26.5의 iPhone 17 Pro 시뮬레이터에서 파일 가져오기와 이전 학습 화면을 확인했습니다. 새 스와이프 화면의 검증 범위는 [검증 기록](VALIDATION.md)을 참고하세요. **본인 아이폰에 서명해 설치하는 단계와 물리적 실기기 동작은 아직 검증하지 않았습니다.**

1. [Apple Xcode](https://developer.apple.com/xcode/resources/)에서 현재 macOS와 호환되는 Xcode를 설치하고 최초 실행 설정을 마칩니다. 이미 설치했다면 다음 단계로 진행합니다.
2. `ios/PodcastStudy.xcodeproj`를 엽니다. 프로젝트 파일은 이미 포함되어 있으며 별도의 패키지 설치가 필요 없습니다.
3. PodcastStudy 타깃 → Signing & Capabilities → 자신의 Apple 계정 Team을 선택합니다. 식별자 충돌이 있으면 Bundle Identifier를 자신의 값으로 바꿉니다.
4. 자신의 아이폰을 연결하고 필요한 경우 기기에서 개발자 모드를 켠 후 실행 대상에 선택하고 Run을 누릅니다.
5. 무료 Personal Team은 프로비저닝이 7일 만료라 재서명이 필요합니다. [Apple 계정 안내](https://developer.apple.com/help/account/basics/about-your-developer-account)

서버에서 로그인하는 기능이나 공개 공유는 없습니다. 학습 파일은 내가 선택한 저장 위치와 아이폰 앱 저장소에 보관됩니다. iCloud Drive를 선택하면 파일 전송에 해당 계정을 사용합니다. 앱 삭제 시 기기에만 저장한 복습 기록도 삭제됩니다. 복습 기록은 `.podprogress` 파일로 따로 백업·복원할 수 있습니다. Mac으로 복습 기록을 자동 동기화하지는 않습니다.

## 복습 기록 백업·복원

앱의 백업 메뉴에서 **복습 기록 백업 저장**로 `.podprogress` 파일을 저장합니다. 파일에는 표현 ID별 북마크·복습 횟수·다음 복습 일정만 담습니다. 에피소드 텍스트와 원음은 원래 `.podstudy` 파일도 함께 보관하세요.

백업은 파일 가져오기나 파일 앱에서 열어 복원합니다. 현재 기록과 합치며 더 최신인 복습 일정·연속 성공 횟수를 유지하고, 총 복습 횟수는 줄이지 않습니다. 북마크는 어느 쪽에든 저장되어 있으면 유지하므로 백업 복원으로 기존 북마크를 해제하지 않습니다. 아직 가져오지 않은 에피소드의 기록도 보관해, 나중에 같은 학습 꾸러미를 가져오면 이어집니다.

잘못된 버전·중복 ID·시간·횟수·크기는 저장 전에 거절합니다. 백업 파일은 4MiB·10,000개 기록까지 지원합니다. 가져오기가 중단된 에피소드는 다음 실행에서 기록을 확인해 복구하며, 손상된 파일을 조용히 덮어쓰지 않습니다.

## 화면과 학습 규칙

- **오늘:** 기한이 된 복습을 우선하고, 새 표현을 섞어 최대 10개를 준비합니다. 기본 7개 복습·3개 신규이며 한쪽이 부족하면 다른 쪽으로 채웁니다. 종료 후 목록을 갱신합니다.
- **에피소드:** 가져온 에피소드의 모든 표현을 원래 순서로 연습합니다.
- **내 표현:** 북마크한 표현을 연습합니다. 항목을 길게 누르거나 VoiceOver의 **저장 해제** 동작으로 북마크를 해제합니다. 북마크와 숙련도는 별개입니다.
- **카드 복습:** 영어 표현·뜻·원문을 처음부터 보여줍니다. 긴 문장은 세로로 스크롤해 읽습니다.
- **오른쪽 스와이프:** 표현을 저장하고 다음 카드로 이동합니다. 이미 저장한 표현은 중복 저장하지 않습니다.
- **왼쪽 스와이프:** 저장 상태를 바꾸지 않고 다음 카드로 이동합니다. 기존 북마크도 유지합니다.
- **원음:** 카드가 나타나면 한 번 자동 재생합니다. 작은 **다시 듣기**로 현재 원음을 처음부터 들을 수 있습니다. 원음이 없으면 실제 사유를 표시합니다.
- 충분히 밀어 확정한 동작만 한 번의 복습으로 기록합니다. 짧은 드래그 취소·세로 스크롤은 기록하지 않습니다. 저장·넘기기는 암기 평가가 아니므로 연속 성공 횟수를 올리지 않습니다.
- 다음 복습은 다음 날로 잡되, 기존에 더 늦게 예약된 일정은 유지합니다. 간단한 초기 규칙이며 학습 효과를 검증한 개인화 알고리즘은 아닙니다.
- 복습 화면의 조작은 닫기와 작은 다시 듣기로 줄였습니다. 완료 화면은 살펴본 표현 수와 이번에 새로 저장한 표현 수를 구분합니다.
- 카드 이동·화면 종료·앱 비활성화·오디오 중단·이어폰 분리 때 재생을 정리하도록 구현했습니다. 자동 재생 실패는 카드 안에 표시하며, 직접 다시 듣기를 시도했을 때도 실패하면 오류를 알립니다.
- VoiceOver 사용자 지정 동작으로 **저장하고 다음 표현 / 그냥 넘기고 다음 표현**을 제공합니다. 큰 글자·동작 줄이기를 고려했으며, 스와이프 감도·오디오 중단·접근성의 물리적 실기기 검수는 남아 있습니다. 상세 규칙은 [스와이프 UX](../docs/SWIPE_UX.md)를 참고하세요.

## 개발·검증

```sh
python3 ios/verify.py
# 핵심 로직만 검사:
python3 ios/check.py
# 실제 내보낸 꾸러미로 같은 검증:
python3 ios/check.py /absolute/path/episode.podstudy
```

`check.py`는 Foundation만 사용하는 Swift 저장·가져오기·복습 코드를 컴파일하고 Python에서 만든 파일을 실제로 읽습니다. CLT의 SwiftBridging 중복 정의가 있으면 임시 VFS overlay로만 우회하며 시스템 파일을 수정하지 않습니다.

### Xcode 없이 공유 화면 확인

```sh
python3 ios/preview_macos.py --open
# 실제 꾸러미도 함께 열기:
python3 ios/preview_macos.py --open --pack /absolute/path/episode.podstudy
```

이 도구는 같은 SwiftUI 화면을 macOS용으로 컴파일합니다. 학습 데이터는 별도의 `PodcastStudy-MacPreview` 폴더에 저장합니다. 아이폰 화면의 에뮬레이터나 iOS 실행 검증이 아닙니다. UI 타입 검사만 하려면 `--typecheck-only`를 사용하세요.

전체 Xcode가 설치된 환경에서는 추가로 다음을 실행합니다.

```sh
python3 ios/verify.py --require-ios
cd ios
swift test
xcodebuild -project PodcastStudy.xcodeproj -scheme PodcastStudy \
  -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

Finder 파일 공유와 파일 앱에서 앱의 Documents 폴더에 학습 꾸러미를 넣을 수 있도록 파일 공유를 켰습니다. 복습 데이터와 원음은 Application Support에 따로 저장됩니다.

Xcode 프로젝트 파일을 재생성하려면 `python3 ios/create_project.py`를 실행합니다. 개인 Team 설정은 생성 스크립트에 포함되지 않습니다.

실기기 확인 순서: 음성 포함 파일 가져오기 → 비행기 모드에서 첫 카드 원음 자동 재생 → 오른쪽 저장·왼쪽 넘기기 → 짧은 드래그 취소·세로 스크롤 → 다음 카드 원음·작은 다시 듣기 → 앱 재실행 후 북마크·일정 확인 → 같은 파일 재가져오기 → 복습 기록 백업·복원 → 잘못된 파일 가져오기. 화면 잠금·오디오 중단·작은 화면·큰 글자에서도 확인해야 합니다.

## 파일 형식 v1

`.podstudy`는 UTF-8 JSON입니다. `format: podcast-study-pack`, `version: 1`, `exportedAt`, `episode`를 포함합니다. 에피소드와 카드 ID는 UUID이며 카드 ID는 에피소드 ID + 표현 + 원문 인용에서 결정합니다. `episode.cards[].audio`는 검증된 원문 한 문장의 MP3 base64, 실제 길이, 원본 시작 초, `kind: original-podcast-sentence`입니다. 음성 준비 실패 시 `audio: null`과 `audioUnavailableReason`을 담습니다. 원문 전체 해석과 생성한 연습 예문·해석은 별도 필드입니다.

가져오기는 64MiB·100카드·개별 음성 8MiB 이하로 제한합니다. 버전·UUID·중복·HTTPS 원본 링크·음성 메타데이터·base64를 검사하고 새 폴더에 쓴 뒤 교체합니다. 실패한 가져오기가 기존 정상 기록을 덮어쓰지 않습니다. 가져온 음성은 별도 MP3로 풀고 manifest에서는 base64를 제거합니다.

검사별 통과 범위와 실제 Mac 미리보기 확인 내용은 [검증 기록](VALIDATION.md)에 정리했습니다.

화면의 색상·글자·버튼·학습 UX 규칙은 [디자인 가이드](../DESIGN.md)를 따릅니다.
