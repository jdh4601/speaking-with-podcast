# English Routine for macOS

설치 위치: `~/Applications/English Routine.app`

## 사용

대시보드 상단은 **이번 주 루틴 캘린더**입니다. 월~일의 할 일과 완료 수를 한눈에 보여주고 바로 체크할 수 있으며, 오늘 칸을 강조합니다.

캘린더 아래 **영어 회화 실력 변화**에서는 분석한 수업을 날짜순으로 비교합니다. 100단어당 실수, 말 더듬·재시작, 한 번에 이어 말한 단어, 내 발화 비율을 골라 볼 수 있습니다.

대시보드 왼쪽은 **지난 수업에서 개선할 점**입니다. 가장 최근 회차에서 실수가 많은 유형을 최대 7개까지 횟수와 대표 실수로 보여주며, 목록은 스크롤할 수 있습니다. 앱을 열면 최근 수업이 선택되고, 수업 선택에서 지난 회차로 바꾸면 개선점과 전체보기가 그 수업 기준으로 바뀝니다. **전체보기**를 누르면 그 수업의 실수 전체를 유형별로 묶어 `틀린 표현 → 고친 표현` 한 줄씩 보여줍니다. **복습 시작하기**를 누르면 고른 수업과 상관없이 모든 회차의 실수를 빈도가 높은 유형부터 카드로 복습합니다. 한글 해석을 보고 영어로 말한 뒤 답을 확인하면 내 문장과 개선 문장이 나타납니다. **외웠어요**를 누른 표현은 빠지지만, 나중에 다시 틀리면 돌아옵니다. 이 표시는 실력 수치에 반영하지 않습니다. **복습 끝내기**로 개선할 점 화면에 돌아갑니다.

대시보드 오른쪽은 **오늘의 표현 복습**입니다. 최근 추출한 에피소드를 기본으로 표시하며 에피소드 선택, 답 확인, 영상의 실제 원문 문장·한글 해석, 원문 문장 듣기, 표현 저장을 지원합니다. 복습 위치는 날짜와 에피소드별로 저장하며 Space(답 확인)·좌우 화살표(이동)·아래 화살표(표현 저장)·Enter(원본 음성 재생) 단축키는 복습 영역에 포커스가 있을 때 동작합니다.

- Dock의 말풍선·파형 아이콘으로 실행합니다.
- 대시보드의 **팟캐스트 학습**에서 YouTube 영상 URL을 입력하고 표현 개수(10·20·30개)를 선택한 뒤 **Enter** 또는 **표현 추출**을 누릅니다. 자막 가져오기부터 표현 추출까지 자동으로 진행하며, 진행 막대에 자막·분석·결과 준비 상태를 표시합니다. 제목과 전사는 별도 입력 없이 내부에서 처리합니다.
- YouTube 영어 자막의 시간정보를 보존하며 발행사 전사로 자동 대체하지 않습니다. YouTube가 요청을 제한하거나 공개 영어 자막이 없는 경우 오류를 안내하며 다시 시도할 수 있습니다.
- 표현에 실제 자막 시작시간이 있으면 **YouTube에서 해당 구간 보기** 링크로 원본 위치를 엽니다. 시간정보가 없으면 위치를 추측해 붙이지 않습니다.
- 표현 개수는 **10개·20개·30개** 중 선택합니다. **표현 추출**은 로그인된 Codex CLI를 실행합니다. 계정 사용량을 소비하며 인터넷 연결이 필요합니다.
- 뜻을 보고 영어로 말한 뒤 답을 확인하고 **표현 저장하기 / 그냥 넘기기**로 진행합니다. 저장한 표현은 앱 상단 **표현 보관함** 또는 카드 위 **저장한 표현**에서 다시 볼 수 있습니다. 보관함은 에피소드별 폴더로 정리되며 영어 표현·뜻·영어 예문·예문 한글 해석을 함께 보여줍니다. 기존 예문의 누락된 해석은 Codex CLI로 보충합니다.
- 원문 인용은 전사와 대조합니다. 새로 만든 연습 예문은 원본 발화가 아닙니다. **원문 문장 듣기**는 공개 MP3에서 해당 표현이 포함된 원문 한 문장 전체를 재생합니다. 전사의 문장 경계를 찾고 실제 인식된 첫 단어·마지막 단어의 시간에 맞춰 자릅니다. 기존의 짧은 표현 음성 캐시는 재사용하지 않습니다. 합성 음성은 사용하지 않습니다.
- 자동 생성 자막은 잘못 인식될 수 있으므로 원음과 확인해야 합니다.

첫 원본 음성 준비 시 에피소드 MP3를 다운로드하고 해당 문장 구간을 로컬에서 분석합니다. 원본이 비공개이거나 타임스탬프가 없거나 문장 전체의 시작과 끝을 확인하지 못하면 재생 오류를 안내하며 합성 음성으로 대체하지 않습니다.

전사 전체 길이 제한은 없습니다. 긴 전사는 겹치는 구간으로 나눠 끝까지 처리한 뒤 중복을 제거하고 선택한 개수로 합칩니다. 진행 상태를 표시하며 완료된 구간은 재시도에 재사용합니다.

원문 문장 해석은 로그인된 Codex CLI로 준비하고 학습 기록에 저장합니다. 대시보드는 표현 아래에 실제 원문 문장과 그 한글 해석을 표시합니다.

마지막 표현을 저장하거나 넘기면 학습 완료 화면에서 에피소드의 전체 표현 수와 저장한 표현 수를 확인합니다. 처음부터 다시 보거나 표현 보관함으로 이동할 수 있습니다. 대시보드는 날짜·에피소드별 완료 상태를 유지합니다.

## 회화 리포트

상단 **회화 리포트**에서 수업 스크립트를 붙여 넣고 **분석하기**를 누릅니다. `You:` 또는 `이름 (You):`로 시작하는 줄을 본인 발화로 인식합니다.

- 회차 리포트: 틀린 부분을 빨간 형광펜으로 표시하고 그 아래에 개선 문장, 한글 해석, 규칙을 보여줍니다. 개선 문장에서 고쳐진 표현은 녹색 형광펜으로 표시합니다. 수업 단어는 `단어 · 뜻 · 예문` 표로 정리합니다.
- 실력 변화: 100단어당 실수, 100단어당 말 더듬·재시작, 한 번에 이어 말한 단어, 내 발화 비율을 회차별로 표시합니다. 합산 점수는 없고, 나빠진 회차도 그대로 표시합니다.
- 반복되는 실수: 유형별·표현별 빈도를 누적합니다.
- 발음 점수는 없습니다. 녹음 없이 평가할 수 없으므로, 상대가 되물은 단어만 "발음 확인 필요"로 표시합니다. 받아쓰기 오류로 의심되는 부분은 "받아쓰기 확인 필요"로 분리하고 빈도에서 제외합니다.
- 분석은 로그인된 Codex CLI를 실행해 계정 사용량을 소비합니다. 본인 발화와 그 바로 앞뒤의 상대 발화 한 줄씩(각 200자 이내)만 보냅니다. Codex가 인용한 문장은 스크립트와 대조하며, 대조되지 않은 항목은 버리고 개수를 표시합니다.
- 실수 건수는 Codex 판단에서 나오므로 회차 간 편차가 있을 수 있습니다. 같은 받아쓰기 서비스를 계속 쓰면 비교가 더 안정적입니다.

## 로컬 저장

- 원본 MP3·단어 타임스탬프·잘라낸 표현 MP3: `~/Library/Application Support/English Routine/audio/`
- 에피소드·전사·추출 표현: `~/Library/Application Support/English Routine/*.json`
- 회화 리포트: `~/Library/Application Support/English Routine/conversations/`. 본인 발화와 분석 결과만 저장하며 원본 스크립트 전체와 상대 발화는 저장하지 않습니다.
- 체크·메모·복습 상태: 앱의 WebKit 저장소
- 기존 웹사이트 브라우저 기록과 앱 기록은 별도입니다.
- 공개 웹페이지에는 로컬 Codex CLI 연결을 배포하지 않습니다.

## 실행 구조

AppKit + WKWebView 창에서 번들된 대시보드를 엽니다. 앱은 `127.0.0.1:47831`에 로컬 Python 서버를 실행합니다. 포트가 사용 중이면 사용 가능한 다른 로컬 포트를 선택합니다. 정상 종료 및 강제 종료 시 서버와 실행 중인 하위 프로세스를 정리합니다. 로컬 API는 실행별 토큰과 Host/Origin 검사로 제한합니다. 서버 시작 오류는 `~/Library/Logs/English Routine/backend.log`에 기록하며, 시작 응답이 15초 안에 없으면 오류를 안내합니다. 포트가 달라지면 WebKit에 저장한 체크·메모·복습 상태는 해당 포트의 별도 저장소로 표시됩니다.

전사 안의 지시문은 데이터로 처리합니다. Codex는 임시 작업 폴더, read-only sandbox, ephemeral 모드로 실행하며 사용자 설정·앱·플러그인·셸·브라우저·다중 에이전트 도구를 비활성화합니다. 결과의 표현·원문·중복을 검증한 뒤 저장합니다.

필요 도구: 현재 Mac에 설치된 Python 3, Deno, Codex CLI, ffmpeg. YouTube 다운로드는 `setup_download.py`로 설치한 앱 전용 `download-runtime`의 yt-dlp와 EJS를 우선 사용합니다. 버전은 `requirements-download.txt`에서 관리합니다. 단어 구간 분석은 Application Support/English Routine/audio-runtime의 mlx-whisper와 로컬 캐시 모델을 사용합니다. 설치·로그인 경로가 바뀌면 `server.py`와 `App.m`의 경로를 조정합니다.

## 빌드 및 확인

```sh
python3 macos/setup_download.py
python3 macos/build.py
python3 -m unittest discover -s macos -p test_server.py -v
node --check macos/web/podcast.js
open "$HOME/Applications/English Routine.app"
```

Xcode Command Line Tools의 SwiftBridging 모듈 중복 문제를 피하기 위해 네이티브 실행 파일과 아이콘 렌더러는 Objective-C / AppKit으로 빌드합니다. 서명은 이 Mac용 ad-hoc 서명입니다.

## 아이폰용 학습 꾸러미

팟캐스트 학습 → 학습 기록에서 에피소드 선택 → **아이폰 학습 꾸러미 만들기** → **꾸러미 저장**으로 `.podstudy` 파일을 만듭니다. 원문 음성 포함을 선택하면 문장 전체의 실제 MP3 클립을 준비합니다. 준비에 실패한 음성은 이유를 표시하고 나머지 표현을 내보냅니다. API 자격증명·전체 전사·전체 원본 MP3는 담지 않습니다.

파일을 AirDrop 또는 iCloud Drive로 옮겨 아이폰의 Podcast Study 앱에서 가져옵니다. 앱 소스·Xcode 설치 안내·지원 범위는 [아이폰 앱 안내](../ios/README.md)를 참고하세요. 내보낸 원본 파일은 `~/Library/Application Support/English Routine/exports/`에 보관됩니다. 아이폰 복습 기록은 아이폰에 저장되며 현재 Mac으로 돌아오지 않습니다.
