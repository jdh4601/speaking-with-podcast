# 스와이프 중심 복습 UX

사용자 요구: 표현을 볼 때마다 버튼을 고르지 않고, **원음을 들으며 오른쪽 저장 / 왼쪽 넘기기**만으로 복습한다. 이 문서는 기존 답 공개·정오 평가 방식보다 우선하는 새 복습 흐름이다. 키컬러 `#0077B6`과 하늘색 면의 흰색 글자 규칙은 유지한다.

## 화면은 한 장의 카드에 집중한다

읽는 순서는 다음과 같다.

1. 상단의 작은 닫기와 현재 위치 `3 / 10`
2. 짧은 에피소드 제목
3. 큰 영어 표현과 한글 뜻
4. 재생 상태와 작은 `다시 듣기`
5. 표현이 포함된 짧은 원문 구절(약 2~3줄, 표현 하이라이트)
6. 하단의 비조작 안내 `← 그냥 넘기기 · 저장 →`

처음부터 표현과 뜻을 보여준다. 발견·듣기·말하기 모드, 답 확인, 다시 연습, 떠올렸어요, 저장 버튼, 북마크 버튼, 이전/다음 화살표, 별도 마치기, 원음 듣기, 반복·배속·정지 버튼은 복습 화면에서 제거한다. 종료는 상단 닫기 하나로 충분하다. 긴 원문 해석·팁·추가 예문은 숨긴다. 원문은 표현을 포함한 약 96자의 구절로 줄이고, 생략은 …로 표시한다. 큰 글자에서는 잘라내지 않고 세로로 읽을 수 있게 한다.

`다시 듣기`는 작은 글자 조작이지만 터치 영역은 최소 44pt를 확보한다. 보조 조작을 큰 입체 CTA로 키우지 않는다. 새 카드가 자동으로 재생되므로 화면을 시작하는 재생 버튼도 필요 없다.

## 두 방향의 의미는 고정한다

| 동작 | 결과 |
|---|---|
| 오른쪽으로 충분히 밀기 | 표현을 저장하고 다음 카드로 이동 |
| 왼쪽으로 충분히 밀기 | 저장 상태를 바꾸지 않고 다음 카드로 이동 |
| 짧게 밀었다 놓기 | 제자리로 돌아옴. 기록·저장·카드 위치가 바뀌지 않음 |
| 세로로 움직이기 | 큰 글자에서도 내용을 읽음. 저장·넘김으로 해석하지 않음 |

이미 저장한 표현을 왼쪽으로 넘겨도 저장을 취소하지 않는다. 오른쪽으로 다시 저장해도 중복 항목을 만들지 않는다. 저장 취소는 보관함의 관리 기능으로 다룰 수 있으며, 복습 도중 왼쪽 동작의 의미를 뒤집지 않는다.

드래그 중에만 카드의 기울기·이동과 `저장` 또는 `넘기기` 피드백을 나타낸다. 초기 화면에 두 개의 가짜 버튼처럼 표시하지 않는다. 오른쪽은 키컬러, 왼쪽은 중립 회색으로 표현하며 빨간 실패 표시를 쓰지 않는다.

## 실수 방지를 위한 제안값

아래 수치는 이 프로젝트의 초기 구현 기준이며 실기기에서 검증된 최적값이라고 주장하지 않는다.

- 가로 의도가 세로 의도보다 뚜렷할 때만 처리한다: `abs(x) > 1.2 × abs(y)`.
- 기본 확정 거리: 카드 폭의 25%, 최소 80pt·최대 120pt.
- 빠른 밀기는 실제 가로 이동이 최소 48pt이고, 같은 방향의 예상 종료 위치가 확정 거리를 넘을 때만 인정한다.
- 짧은 이동, 반대 방향의 예상 종료값, 세로 중심 이동은 취소한다.
- 애니메이션·저장이 진행 중일 때는 두 번째 입력을 받지 않는다. 한 카드의 확정 동작은 한 번만 기록한다.
- 기록 저장이 성공한 뒤에만 카드를 넘긴다. 실패하면 현재 카드와 기존 기록을 보존하고 재시도할 수 있게 한다.

원문을 담은 세로 ScrollView와 가로 카드 동작은 함께 사용할 수 있어야 한다. 가로 동작을 잡으려고 모든 세로 입력을 가로채지 않는다. 표현 영역의 텍스트 선택이 가로 드래그와 충돌한다면, 카드 본문은 읽기에 집중하고 텍스트 선택은 맥락 영역으로 제한한다.

## 음성은 카드의 생명주기를 따른다

- 첫 카드가 나타났을 때와 다음 카드가 도착했을 때 표시된 원문 구절을 한 번 자동 재생한다. 실제 단어별 시각으로 첫 단어에서 시작해 마지막 단어에서 끝낸다. 20ms 단위로 플레이어 시각을 확인해 종료하며, 운영체제 스케줄링에 따른 오차는 있을 수 있다. 원문 전체 길이를 글자 수로 나눠 추정하지 않는다.
- 아직 보이지 않는 다음 카드의 음성을 미리 재생하지 않는다. 부분 드래그 후 취소했다고 처음부터 다시 재생하지 않는다.
- 스와이프를 확정하면 이전 음성을 즉시 정리한다. 다음 카드가 나타난 뒤 새 음성을 시작하며 겹쳐 들리지 않게 한다.
- `다시 듣기`는 현재 화면의 동일한 짧은 구절을 처음부터 한 번 재생한다. 반복 횟수·속도 선택을 다시 노출하지 않는다.
- 카드 종료, 학습 닫기, 앱 비활성화, 오디오 중단, 이어폰 분리 때 음성과 예약된 작업을 정리한다. 외부 중단 뒤에는 자동 재개하지 않는다.
- 원음이 없는 카드도 원활하게 넘길 수 있다. `원음 없음 · 글로 복습해요`를 짧게 표시하고, 비활성 재생 버튼을 남기지 않는다.
- 자동 재생 실패는 작은 상태 안내로 표시한다. 카드마다 모달 오류를 반복해 띄우지 않는다. 사용자가 직접 다시 듣기를 눌렀을 때도 실패하면 원인과 재시도 방법을 알려준다.

재생 중·완료·실패 문구는 상태 정보이며 또 다른 버튼이 아니다. 저장 안내를 띄우기 위해 다음 카드의 재생을 지연하거나, 화면 낭독과 긴 상태 메시지를 동시에 강제로 읽게 하지 않는다.

## 복습 내역과 암기는 구분한다

확정된 스와이프는 한 번의 중립적인 복습·노출 기록이다. 오른쪽 저장은 관심 표현을 고르는 동작이며, 기억했거나 발음이 맞았다는 증거가 아니다. 양쪽 모두 암기 성공 횟수를 올리지 않는다.

새 표현의 다음 복습은 다음 날로 잡고, 기존에 더 늦게 예약된 일정은 유지한다. 카드를 보기만 하거나 드래그를 취소했을 때는 기록하지 않는다. 이 일정은 단순한 초기 제품 규칙이며 학습 효과가 검증된 알고리즘이라고 표현하지 않는다.

완료 화면은 `표현 10개를 살펴봤어요`처럼 실제 스와이프한 개수를 보여준다. 저장 개수를 함께 표시한다면 다음 중 한 기준을 명시한다.

- `이번에 새로 저장한 표현 N개`: 기존 미저장 → 저장으로 바뀐 항목만 센다.
- `이 중 저장된 표현 N개`: 이번 세션에 등장한 표현의 현재 저장 상태를 센다.

두 수치를 혼합하거나, 이미 저장되어 있던 표현을 새 저장 성과로 표시하지 않는다. 완료 후에는 닫기 한 개만 둔다. 중간 종료는 이미 처리한 카드의 기록만 남긴다.

## 접근성에서도 같은 두 동작을 제공한다

화면에 버튼을 추가하는 대신 카드의 VoiceOver 사용자 지정 동작으로 `저장하고 다음 표현`, `그냥 넘기고 다음 표현`을 제공한다. 방향만 말하지 않고 행동 결과를 읽어준다. 짧은 원문은 독립적으로 읽을 수 있어야 하며, 모든 내용을 하나의 거대한 접근성 레이블로 묶지 않는다.

동작 줄이기 설정에서는 회전·카드 날리기 효과를 없애거나 짧게 대체하지만, 방향과 결과 문구는 유지한다. 저장/넘기기를 색으로만 구분하지 않는다. 큰 글자에서는 카드 안을 세로로 읽고 닫기·다시 듣기·스와이프 안내가 잘리지 않게 한다.

## 검수해야 할 흐름

- 첫 카드 자동 재생, 작은 다시 듣기, 다음 카드에서 이전 음성 중단
- 오른쪽 저장, 왼쪽 넘기기, 기존 저장 표현을 왼쪽으로 넘겨도 보존
- 짧은 드래그 취소와 세로 스크롤이 기록을 만들지 않음
- 빠른 연속 입력이 중복 저장·중복 복습·두 장 이동을 만들지 않음
- 원음 없는 카드와 손상된 음성에서도 카드 이동 가능
- 마지막 카드 완료와 중간 닫기의 실제 처리 수 표시
- 앱 비활성화·이어폰 분리·VoiceOver·동작 줄이기·큰 글자

문서 작성 시점에 이 새 흐름의 코드·시뮬레이터 동작은 확인하지 않았다. 실제 검증 결과는 구현 담당자가 별도로 기록한다.

기존 꾸러미에 단어별 시각이 없고 전체 문장이 화면에 들어오지 않는다면 짧은 음성 재가져오기를 안내한다. 기존 캐시는 Mac에 남은 단어 정렬 결과로 보강할 수 있다. 주변 전사가 실제 음성 인식과 다르면 표현을 포함한 검증 가능한 짧은 구절로 줄인다.
